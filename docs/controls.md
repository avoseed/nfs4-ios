# 조작 확인 기록

NFS4 원본 실행 파일의 기본 키 테이블을 guest VA `0x005BCA14`에서 직접 확인했다.

| 기능 | 테이블 값/기본 키 | 호스트 DIK |
|---|---|---|
| 조향 | 좌/우 방향키 (`04 4B`, `04 4D`) | CB / CD |
| 가속/브레이크 | 위/아래 방향키 (`04 48`, `04 50`) | C8 / D0 |
| 시점 | C (`04 2E 00 43`) | 2E |
| 경적/사이렌 | H (`04 23 00 48`) | 23 |
| 후방 보기 | B (`04 30 00 42`) | 30 |
| 리셋 | R (`04 13 00 52`) | 13 |
| 스파이크 | S (`04 1F 00 53`) | 1F |
| 일시정지/확인/지도 | Esc / Enter / Tab | 01 / 1C / 0F |

기능 이름과 테이블 순서는 재사용 코드 및 게임 기본 배치와 대조했다. 모든 버튼을 각각 실행 검증한 것은 아니다. Esc 일시정지, Enter 메뉴 선택, 마우스 메뉴 선택과 조이스틱 Y=-1 가속은 PC에서 실행 확인했다. 테이블에 있는 핸드브레이크·기어·라이트는 터치 화면에 추가하지 않았다.

## 메뉴와 레이스 판별

NFS4는 메뉴와 레이스가 모두 640x480일 수 있어 해상도만으로 구분할 수 없다. `recomp/run/trace_menu/trace.txt`와 `trace_race/trace.txt`를 비교해 메뉴 hit-test 함수 `0x00491990`, 레이스 제어 함수 `0x0043C260`의 호출을 관찰한다. 원본 게임 상태는 변경하지 않는다. 일시정지 뒤에도 레이스 제어가 호출되므로 최근 150ms의 메뉴 호출을 우선한다. PC에서 메뉴·주행·일시정지 구분 로그를 확인했다. iOS 버튼 전환 자체는 실기기 확인이 필요하다.

## iOS 구성

왼쪽 아날로그 조향, 오른쪽 가속/브레이크, 후방 보기·스파이크·경적/사이렌·오토 가속·일시정지·지도·시점·확인·리셋. 메뉴 전용 방향키·확인·뒤로·이름 입력. 게임패드 연결 시 터치 숨김. 편집기·햅틱·투명도 설정은 기존 플랫폼 구현을 재사용했다.

가속 키/터치/트리거는 가상 조이스틱 축으로도 전달한다. PC의 키 스크립트는 iOS의 축 합성 계층을 거치지 않으므로 주행 검증에서는 `jy-1`을 사용했다.

## 오토 가속 (0.1.4)

오토 가속 버튼을 탭하면 켜지고 초록색으로 표시된다. 켜진 상태에서 터치 브레이크, 패드 L2 또는 D-pad 아래를 누르면 브레이크를 유지하는 동안 자동 가속을 잠시 멈춘다. 이때 버튼은 흐린 초록색이며, 브레이크를 떼면 자동 가속이 다시 시작된다. 브레이크는 오토 가속 설정을 끄지 않는다. 버튼을 다시 탭하거나 메뉴 화면으로 전환하면 꺼진다.

기존 입력 초기화도 유지된다. 패드 연결·해제, 조작 배치 편집 진입·종료 시에는 오토 가속이 꺼진다. L2의 일시 중지는 기존 트리거 합성값 `L2 - R2 > 0.2`를 기준으로 하므로, 두 트리거를 함께 눌러 합성값이 이 기준 이하이면 L2만으로 일시 중지되지 않는다. 수동 가속과 브레이크의 동시 입력도 기존 축 합성 규칙을 따른다.

NFS3 1.6.4와 관련 함수가 일치함을 소스로 대조했다. 실제 함수 추출 시험은 UIKit 표시를 대체한 PC 입력 로직 검증이며, iOS 버튼 색·터치·패드 실기기 동작은 별도 확인이 필요하다.

## 터치 조작 디자인 (0.2.0)

버튼은 어두운 반투명 원판과 흰 링, 흰 아이콘으로 표시한다. 주요 버튼에는 이름을 함께 표시하고, 왼쪽 위의 일시정지·지도·시점은 아이콘만 표시한다. 같은 기능의 패드 입력은 링 오른쪽 위의 배지로 안내한다. 오토 가속은 별도 패드 배지가 없으며, 켜짐은 초록색, 브레이크로 잠시 멈춘 동안은 흐린 초록색으로 표시한다.

| 기능 | 패드 배지 |
|---|---|
| 가속 | RT |
| 브레이크 | LT |
| 후방 보기 | R↓ (오른쪽 스틱 아래) |
| 스파이크 | R3 (오른쪽 스틱 누르기) |
| 경적·사이렌 | L3 (왼쪽 스틱 누르기) |
| 일시정지 | B |
| 지도 | R← (오른쪽 스틱 왼쪽) |
| 시점 | Y |
| 확인 | A |
| 리셋 | R→ (오른쪽 스틱 오른쪽) |

조향은 흰 링의 캡슐 형태이며, 누르고 움직이는 동안 노브와 중앙에서 이어지는 막대가 조향량을 보여 준다. 기본 배치는 왼쪽 아래 조향과 그 오른쪽 끝 위의 후방 보기, 오른쪽 아래 가속·브레이크다. 가속 위에는 오토 가속·리셋, 브레이크 위에는 경적·스파이크를 각각 두 줄로 배치한다. 왼쪽 위에는 일시정지·지도·시점을 세로로, 오른쪽 위에는 확인을 둔다. ⚙︎는 주행 중 왼쪽 안전 여백이 충분하면 그 여백 위쪽에, 여백이 없으면 위쪽 중앙에 표시한다. 메뉴에서는 오른쪽 여백 위쪽에 표시한다.

편집기 배치 저장 키는 `overlay3`이다. 예전 `overlay` 배치의 위치·크기·햅틱 설정을 이어받지 않아 새 기본 배치가 적용되며, 이후 편집한 배치는 `overlay3`에 저장한다. 버튼 전체 표시 불투명도의 기본값은 100%이고 원판 자체는 반투명이다. 기존 `overlayAlpha`에 저장한 투명도는 유지하므로 업데이트만으로 모두 100%가 되지는 않는다. 설정에서 100%를 선택하거나 편집기의 기본 배치 되돌리기를 사용하면 기본 투명도를 적용할 수 있다. 되돌리기는 현재 배치 편집도 함께 초기화한다.

NFS3 1.8.0의 관련 디자인 블록 10개를 소스로 대조했다. 기존 조이스틱 합성과 패드 입력 로직은 유지된다. 이 확인은 소스 검토이며, iOS 컴파일·실제 화면 배치·배지 겹침·누름/해제·조향 노브·편집 저장 동작은 빌드 및 실기기 검증이 필요하다.
